🏠 Overview
What is MicrOrbit?

The MicrOrbit · Action Request System is a standalone, browser-based operational dashboard for managing Action Requests (ARs). It runs as a single HTML file with no server, installation, or internet connection required after initial load.

Key Capabilities

  • Real-time day-based AR aging (Past Due / 1–3d / 4–7d / 8–15d / 16–30d / 30+d)
  • 5 operational statuses including the new Past Due escalation status
  • Inline cell editing — click any field to edit immediately
  • Import from Excel (.xlsx/.xls) and CSV files via drag-and-drop
  • Priority queue showing critical items needing immediate action
  • Owner workload distribution chart
  • Report builder with email integration
  • 7 professional themes including Light Corporate for office use
  • Fully SharePoint compatible — just upload the HTML file
💡 Recommended for daily use: Open the Dashboard tab each morning. Review the alert banner and Priority Action queue. Address Due Today items first, then Past Due items.

Tab Structure

  • Dashboard — Operational command center: KPIs, priority queue, AR list, charts
  • AR Records — Full table with all filtering, sorting, CRUD operations
  • Database — Upload new data files, view statistics, export data
  • Reporting — Generate and email operational reports
  • Admin — Themes, settings, expert recommendations
  • Manual — This guide
📊 Dashboard Tab
Operational command center

Alert Banner

A coloured banner appears at the top when there are critical items. Click it to jump directly to the AR Records tab. Red = critical (overdue ARs exist). Green = all clear.

KPI Cards (8 total)

Six clickable cards showing: Total ARs, Active, Past Due Status, On Hold, Overdue, and Due Today. Click any card to expand a filtered list of matching ARs directly below. Click the same card again to collapse. Cards update instantly with any data change.

Priority Action Queue

Shows ARs that require immediate attention today — specifically Due Today and items 8+ days overdue. This is your daily action checklist. Items are sorted by urgency.

All AR Records (Dashboard View)

A compact, paginated table showing all ARs directly on the dashboard. Use the status filter dropdown to quickly view just Active, Past Due, or Hold items without switching tabs.

Sidebar Charts

  • Aging Distribution — Horizontal bar chart showing count per aging bucket
  • Status Breakdown — Donut chart of status distribution
  • Owner Workload — Bar chart showing ARs per owner (with overdue count)
  • Action Type Mix — Donut chart of AR categories
📋 AR Records Tab
Full data management interface

Search & Filters

  • Search box — searches AR #, subject, owner, action type, and notes simultaneously
  • Status filter — filter by Active / Past Due / Hold / Completed / Cancelled
  • Aging filter — filter by specific aging bucket
  • Owner filter — filter by assigned person or team
  • ↺ Reset — clears all active filters

Sorting

Click any column header to sort. Click again to reverse. The ↕ symbol indicates sortable columns.

Pagination

Records are paginated (default 25 per page). Use the page controls at the bottom of the table. Change rows per page in Admin settings.

Adding a New AR

Click the ＋ Add AR button to open the Add Record modal. AR # and Subject are required fields. All other fields are optional.

Deleting

Hover any row → click the red ✕ button → confirm deletion in the dialog.

🗄 Database Tab
Upload and manage AR data files

Uploading a File

  1. Go to the Database tab
  2. Drag & drop your file onto the upload zone, or click to browse
  3. Supported formats: .xlsx, .xls, .csv
  4. The importer auto-detects column names — no exact format required
  5. Your existing session data is replaced immediately upon successful import
⚠️ Important: Uploading replaces ALL current session data. Export first if you have unsaved edits you want to keep.

Column Auto-Detection

The importer scans column headers for keywords. See the column reference table in the Database tab for accepted names.

Data Freshness

If the uploaded data contains ARs with dates older than 90 days, a freshness warning will appear. This is informational only — aging still calculates correctly against today's date, but numbers may appear large due to old data.

Exporting

Use ⬇ Export CSV to download your current session data (including all manual edits) as a CSV file. Use ⬇ Export JSON for structured data exchange.

✏️ Editing Records
Inline editing and full record editing

Inline Cell Editing

Click any highlighted cell value directly in the table to edit it:

  • Status badge — click to open a dropdown with all 5 statuses
  • Due Date — click to open a date picker
  • Action Type — click to type a new value
  • Owner — click to type a new name or team
  • Notes — click to edit the notes/reminders text
💡 Press Enter to save an inline edit. Press Esc to cancel.

Full Record Edit Modal

Hover any row → click the ✎ (pencil) button → edit all fields at once in the modal popup.

Setting Past Due Status

When an AR has been delayed and requires escalation, click the Status badge → select Past Due. This is an explicit operational flag distinct from the automatic aging calculation.

Live Data Sync

All edits immediately update: Dashboard KPIs, Priority Queue, Charts, Aging calculations, and Report previews.

🏷 Status System
5-state operational status model

Status Definitions

  • Active — AR is open, being worked, and not yet considered past due by the team
  • Past Due — AR has been explicitly flagged as overdue/escalated by the team. This is a manual status change, not automatic. Use this when an AR has missed its deadline and requires immediate attention.
  • Hold — AR is paused awaiting direction, approval, or additional information. Not included in overdue calculations.
  • Completed — AR has been finished and signed off. Excluded from aging calculations.
  • Cancelled — AR has been withdrawn and is no longer required.
💡 Difference between "Past Due" status and aging:
Aging is calculated automatically (days since due date). It tells you how long something has been overdue.
Past Due status is set manually by your team. It signals operational escalation — this AR needs someone to act on it now.
⏱ Aging System
Day-based real-time aging calculation

How Aging is Calculated

Aging = Today's date − Due Date (in calendar days). Calculated fresh on every page render.

Aging Buckets

  • Upcoming — Due date is in the future (negative days)
  • Due Today — Due date = today (0 days)
  • 1–3 Days — Mildly overdue
  • 4–7 Days — Moderately overdue
  • 8–15 Days — Significantly overdue
  • 16–30 Days — Seriously overdue
  • 30+ Days — Critical backlog
💡 Hold, Completed, and Cancelled records are excluded from aging calculations. Only Active and Past Due records are aged.

🏢 Deployment
Getting this dashboard into your office environment

SharePoint Deployment (Recommended)

  1. Save the _AR_TRACKER_v4.html file to your computer
  2. Open SharePoint → navigate to your team's document library
  3. Upload the HTML file to the library
  4. Right-click the file → Copy link
  5. Share the link with your team — they can open it directly in their browser
  6. Pin the link as a bookmark or Teams tab for easy daily access
💡 SharePoint will serve the HTML file directly. No special permissions or web parts needed. Works in Edge, Chrome, Firefox, and Safari.

Network Drive / Shared Folder

  1. Save the HTML file to your shared network drive
  2. Users open it directly in their browser from the file path
  3. Works offline once the file is accessed

Teams Integration

  1. Upload to SharePoint as above
  2. In Microsoft Teams → click + to add a tab → choose Website
  3. Paste the SharePoint direct file URL
  4. Team members can access the dashboard from within Teams
⚠️ Session data only: All edits are browser-session based. Always export data using ⬇ Export CSV before closing the browser if you want to preserve edits.

Browser Compatibility

Tested and working in: Microsoft Edge (recommended for government), Google Chrome, Mozilla Firefox, Apple Safari. Internet Explorer is not supported.

❓ FAQ
Common questions

Why do I see huge aging numbers like +500 days?

The seed data contains AR records from 2023. Aging is always calculated vs today's date. When you upload your actual current data from your AR system, the numbers will reflect real operational aging.

What's the difference between "Past Due" status and the aging calculation?

Aging is automatic (days past due date). "Past Due" is a manual status your team sets to signal escalation. Both serve different purposes — aging gives you the timeline, Past Due status triggers priority treatment.

Will my changes be saved if I close the browser?

No — all edits are session-based only. Use Database → Export CSV to save your work before closing.

Can multiple people use this at the same time?

Yes — but each person has their own independent session. Edits are not shared between users in real time. For shared editing, each user should start from the same exported CSV file.

Can I add this to my SharePoint intranet page?

Yes. Upload the file to a document library and share the direct link. You can also embed it in a SharePoint page using the Embed web part with the file URL.

How do I update the dashboard with new data?

Go to Database tab → drag and drop your new file → data replaces immediately. No re-download needed.
