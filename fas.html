MicrOrbit · Facilities & Accommodation System

A centralized request management system for all facilities, accommodation, and workplace services. Replaces email-based requests with a tracked, accountable, real-time system.

Submitting a Request

Click New Request in the sidebar or top bar. Select a category and subcategory, describe your request in detail, set priority if urgent, and submit. You'll receive a request ID and can track status under My Requests.

Request Queue (Accommodation Team)

The Queue Manager shows all requests. Assign requests to team members, update status, add internal notes, and track SLA compliance. Red aging badges indicate SLA breach.

Onboarding Checklists

Create a new onboarding record for each new employee. The checklist covers access setup, desk assignment, equipment, supplies, and building orientation. Each item can be assigned to a specific team member and checked off when complete.

Asset Register

Track all branch assets including furniture, electronics, and equipment. Record asset tag numbers, assignments, location, and condition. Use the transfer function to reassign assets between staff.

️ Cloud Sync

All data is automatically saved to the cloud and shared in real time. Changes made by the accommodation team are visible to staff within seconds.
